🟢 Module 1: CSS Basics

CSS = Cascading Style Sheets

✅ What is CSS..?

CSS ka use HTML webpage ko design/styling dene ke liye hota hai.

✅ Types of CSS Inline,Internal,External

1. Inline CSS

=> Inline CSS directly HTML element ke andar style attribute me likhte hain.

1. Internal CSS

=> Internal CSS ko HTML document ke <head> ke andar <style> tag me likhte hain.

1. External CSS

=> External CSS me CSS ko alag .css file me likhte hain.

✅ CSS Syntax

=> CSS ka basic syntax is tarha hota hai:

selector { property : value; }

=> Example:

h1 { color : blue; }

=> Isme:

  • h1 = Selector
  • color = Property
  • blue = Value

✅ CSS Comments

=> CSS Comments ka use CSS code ke andar notes ya explanation likhne ke liye hota hai. 

/* This is a CSS comment */
